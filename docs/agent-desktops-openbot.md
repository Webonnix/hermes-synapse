# OpenBot в Десктопах агентов: план интеграции и модель угроз

OpenBot (openbot.run, github.com/nightly-labs/openbot) — сервер команды агентов
(Electron), которым управляют из его собственных приложений через облачный
сервер аккаунтов. В Hermes он запускается как второй тип десктопа агента
(`openbot`) рядом с CLI-агентами (`agent`: Grok Build, OpenCode).

## Что получилось

| Возможность | Как |
|---|---|
| Изоляция | gVisor (`runsc`), корень read-only, без capabilities, `no-new-privileges`, лимиты 6 ГБ / 4 CPU / 2048 pid |
| Сеть | dev-net + dev-egress-net, свой `resolv.conf` (внутренние имена не резолвятся), `hermes-backend` в `/etc/hosts` |
| API Hermes | недоступен: `net_guard.py` отдаёт с интерфейса песочниц только `/agent-llm/` |
| Модель | локальная Qwen (Strata) через `/agent-llm/v1` с токеном десктопа, в общей очереди GPU с фоновым приоритетом |
| OmniRoute | модели роутера (`omniroute/<id>`) — по флагу, по шаблонам, с суточным лимитом $ и запросов на десктоп, учёт в `router_usage_log` |
| Видимость | VNC обоих экранов: `:0` — окно OpenBot и его браузер, `:1` — рабочий стол агентов |
| Вход | `openbot login` / `openbot mobile-connect` в окне «OpenBot terminal» на экране `:0` |
| Аварийная остановка | kill switch Control Plane отключает все модели `/agent-llm` |

## Модель угроз

**Агенты OpenBot не спрашивают разрешений.** Они работают в режиме полного
доступа (`danger-full-access`), и у OpenBot нет механизма, через который их
действия можно было бы провести через Control Plane. Поэтому граница для них —
сам десктоп:

- выход из песочницы — только через ядро gVisor, а не ядро хоста;
- к сервисам Hermes (база, Qdrant, llama, docker-proxy) — нет маршрута и нет имён;
- к API бэкенда — 403 на всё, кроме `/agent-llm/`;
- к модели — только своим токеном, с очередью, лимитами и kill switch;
- к ключам — ни `ROUTER_API_KEY`, ни `LLM_PROXY_TOKEN` в десктоп не попадают.

**Что остаётся открытым осознанно.**
- Интернет: OpenBot нужен его сервер аккаунтов, Signal и TURN; агентам — сайты.
  Всё, что есть в доме десктопа (входы в аккаунты, файлы), агент может унести наружу.
  Не входите в десктопе в аккаунты, которые не готовы доверить его агентам.
- Облако OpenBot хранит аккаунт, членство и приглашения; чаты и файлы, по их
  документации, идут напрямую (WebRTC), через их TURN при необходимости.
- Вызовы OmniRoute из десктопов не проходят шлюз приватности Hermes: это
  собственная работа агента, переписывание tool-calling диалогов их ломает.
  Поэтому внешние модели выключены по умолчанию.
- Образ OpenBot — сторонний (закреплён по digest). Его attestation проверяется
  `gh attestation verify oci://ghcr.io/nightly-labs/openbot:<версия> --repo nightly-labs/openbot`
  перед обновлением digest.

**Лицензия.** PolyForm Noncommercial 1.0.0: для себя — да, в коммерческий
Client Kit — нет. Отсюда отдельный флаг `OPENBOT_DESKTOPS_ENABLED`.

## Включение

```bash
docker compose build openbot-desktop
```

В окружении бэкенда:

- `OPENBOT_DESKTOPS_ENABLED=true` — тип `openbot` во вкладке «Десктопы агентов»;
- `AGENT_LLM_EXTERNAL_ENABLED=true` — модели OmniRoute для всех десктопов;
- `AGENT_LLM_EXTERNAL_MODELS=ds/*,…` — какие модели (шаблоны, по умолчанию `*`);
- `AGENT_LLM_EXTERNAL_DAILY_USD`, `AGENT_LLM_EXTERNAL_DAILY_REQUESTS` — суточный лимит
  на десктоп (по умолчанию $5 и 500 запросов; модели без цены в `cost.py`
  ограничены только числом запросов);
- `AGENT_LLM_PER_DESKTOP` — одновременных запросов на десктоп (по умолчанию 1,
  остальные ждут в очереди).

## Подключение (для владельца)

1. Вкладка «Десктопы агентов» → имя → тип **OpenBot** → «Запустить».
2. «Управлять» → в окне «OpenBot terminal» `openbot login` (email и код из письма).
3. openbot.run/app или приложение OpenBot с тем же аккаунтом — сервер в списке.
4. В OpenBot добавить провайдера «Custom OpenAI-compatible» с Base URL, ключом и
   моделью из карточки «Подключение OpenBot» во вкладке.
5. Телефон: `openbot mobile-connect` в том же терминале, QR — в приложении.

## Дальше

  TURN, провайдеры) вместо открытого интернета.
- Сохранение журнала и автоостановка простаивающих десктопов.
